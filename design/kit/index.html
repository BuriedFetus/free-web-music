Device kit, sheet 1: Basalt

Every device in the library is built from one template. This is the first full device: drag knobs and faders, click or type keys (A W S E D F T G Y H U J K). The scope shows the wave as you play. Envelopes has Amp and Filter tabs. LFO 1 (Free / Retrig / Poly) moves the cutoff. Modulation works both ways: "Assign LFO 1" or "Assign Amp/Filter env", then click any knob or envelope fader; each route gets its own depth slider. Below, the sequencer lane is a full piano roll with live recording, loop and automation (Space = play/stop). A simulated collaborator, Mira, is tweaking and playing it as well. The skin buttons show how a host app can restyle everything through tokens alone (docs/THEMING.md).

    One template, many materials

    A new device only picks a casing palette and its controls. The parts and the way they behave stay the same, so the library can grow without new UI code per device.

    Knob states, including other people

    Presence is attached to controls, not screen positions, so it shows correctly in everyone's own window layout.

    Editor colours

    The piano roll and sequencer use one deep blue so they read as "the sequencer world", separate from device casings.
